# ANDILE: S1·E1 cold open ("Hemingway's"), a code-rendered anime film

A 30-second cel-shaded anime film. Everything is generated by code:
- **No image generation and no video model.** three.js + headless Chromium (SwiftShader, CPU only) + numpy audio.
- **Real 3D:** rigged characters, keyframed choreography, a moving camera, 14 shots.
- **Deterministic:** frame `N` always renders the same image; one `timeline.json` drives picture and sound.

## Render
```bash
npm install                 # three@0.160 (Playwright + Chromium come with the environment)
python3 -m pip install numpy pillow
./build.sh both 3           # audio → 16:9 + 9:16 frames (3 workers each) → MP4s, contact sheets, posters
./build.sh 16x9             # or one format
node render.js --w=1280 --h=720 --out=frames/16x9 --frames=379   # re-render any single frame
```
Outputs land in `out/`: `andile_s1e1_coldopen_16x9.mp4`, `andile_s1e1_coldopen_9x16.mp4`, `contact_*.jpg`, `posters/`.
Render cost: about 1 s per frame per worker on a 4-vCPU box (720 frames ≈ 12 min with 3 workers).

## Files
| File | Role |
|---|---|
| `style-guide.md` | look, palette, cast, camera grammar (gate 1) |
| `shotlist.md` | 14 shots with timestamps, entry/exit states, purpose (gate 1) |
| `timeline.json` | the single source of truth: shots, walk cycles, cues, music sections, text |
| `src/main.js` | renderer, post-FX (bloom, grade, grain, impact frames, speed lines), camera, overlays, `renderAt(frame)` |
| `src/rig.js` | procedural rigged cast + pose library + keyframe evaluation |
| `src/sets.js` | ocean at dusk, rainy neon street, club interior |
| `src/shots.js` | per-shot camera moves and character choreography |
| `src/toon.js` | cel shader, outlines, seeded RNG, text/window textures |
| `audio.py` | synthesised score + SFX from the same timeline |
| `render.js` / `build.sh` / `contact.py` / `posters.py` | render pipeline |
| `review.md` | gate 3 scores and gate 4 fixes |
| `assets.md` | assets list and what still needs human review |
