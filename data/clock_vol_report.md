## Power check (planted effects on Null A)

Null A generator (seed 5) with AR(1) autocorrelation phi in the 1-min increments (1-min variance kept; 4h variance ratio ~ (1+phi)/(1-phi)). Seas20 cells, pooled over all periods. `Δ vs phi 0` = avg R minus the same-seed phi = 0 run (SE = root sum of squares, conservative for a paired design). `z vs exp` = avg R against the cost-only expectation (= the costs-off R in SE units) — **this is the power column**: planted follow-through must push the A cells up, planted reversion the B cells. `Δ vs phi 0` mixes in a geometry change (phi alters the 4h variance, hence seas20, hence R and cost-in-R), so it moves A and B the same way and is not the test.
